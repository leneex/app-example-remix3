# Remix 3

Example [Remix 3](https://remix.run/) app. Remix 3 is a new web framework from the Remix team, built on web standards and its own component model instead of React.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `44100` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in development mode with watch
npm run dev

# start dev server with HMR
npm run hmr

# start production server
npm run start
```

Requires Node.js 24.3 or later.
